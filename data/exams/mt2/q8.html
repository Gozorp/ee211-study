Walk from B to A along the circuit (B → R3 → battery → R1 → R2 → A) and add up the voltage changes. Only one element changes the voltage.

  1. A and B are open terminals: nothing is connected between them. The question asks for the open-circuit voltage \(V_{AB}\). This is exactly how the Thévenin voltage is defined: \(V_{TH} = V_{AB}\) with nothing connected to A–B.

  2. Current needs a closed loop. Follow the only possible path: + terminal → \(R_1\) → \(R_2\) → A → gap → B → \(R_3\) → − terminal. The gap between A and B is an open circuit, so the loop is broken and

    \[ I = 0\ \text{A} \quad\text{in } R_1,\ R_2 \text{ and } R_3 . \]

    The same current flows in every element of a single series path, so all three resistors carry zero current.

  3. Ohm's law for each resistor: \(V_R = I R\), with \(V_R\) in volts, \(I\) in amperes, \(R\) in ohms.

    KVL (Kirchhoff's voltage law): going around any closed path, including one that crosses the gap from A to B, the voltage rises and drops add to zero. Walking from B to A:

    \[ V_{AB} = V_A - V_B \]
    \[ V_{AB} = V_s - V_{R1} - V_{R2} - V_{R3} \]

    The walk rises by \(V_s\) through the battery and passes through each resistor. Each resistor term is a drop in the direction its current would flow. Here every resistor term is zero anyway.

  4. \[ V_{R1} = (0\ \text{A})(10\ \Omega) = 0\ \text{V} \]
    \[ V_{R2} = (0\ \text{A})(10\ \Omega) = 0\ \text{V} \]
    \[ V_{R3} = (0\ \text{A})(20\ \Omega) = 0\ \text{V} \]
    \[ V_{AB} = 12\ \text{V} - 0 - 0 - 0 = 12\ \text{V} \]

  5. Take the battery's − terminal as 0 V. Then its + terminal is at 12 V. A resistor with no current drops nothing, so both of its ends are at the same voltage:

    Terminal A connects (through \(R_1\) and \(R_2\), with no voltage drop) to the battery's + terminal, the long plate on top. Terminal B connects (through \(R_3\)) to the − terminal. So A is the positive terminal: \(V_{AB} = +12\ \text{V}\). Measured with the red lead on A and the black lead on B, an ideal voltmeter reads +12 V.

\(V_{AB} = 12\ \text{V}\) (A positive with respect to B). The resistor values do not affect it.

  • Every point of a wire or resistor that carries no current is at one voltage. So A is at the battery's + voltage and B is at its − voltage. Their difference must be the battery voltage.
  • Limit check: connect a load \(R_L\) across A–B. Then a current \(I = 12/(10 + 10 + 20 + R_L)\) flows and \(V_{AB} = 12\,R_L/(40 + R_L)\). As \(R_L \to \infty\) (open circuit) this tends to 12 V, the same answer.
  • Thévenin view: the whole circuit is a 12 V source in series with \(R_1 + R_2 + R_3 = 40\ \Omega\). The open-circuit voltage of a Thévenin equivalent is \(V_{TH}\) = 12 V.
  • Using a voltage divider (6 V or 3 V) when no current flows. A divider only works when the same current flows through the resistors in series.
  • Answering 0 V because "there is no current". Zero current makes the resistor voltages zero, not the source voltage.
  • Getting the sign backwards. Check which battery plate (long = +) each terminal is wired to.
  • Thinking the resistors' values matter. Here they are distractors; with A–B open they only matter for \(R_{TH}\).

Approach for a similar problem. First ask: is there a closed loop that includes the terminals?

  • Terminals open, single series path (this question): no current. Every resistor in that path drops 0 V, and \(V_{AB}\) is the sum of the source voltages along the path, with their polarities.
  • A resistor connected directly across A–B inside the network: now a loop exists. Find the loop current with Ohm's law (\(I = V_s/R_{total}\)) and \(V_{AB}\) is that resistor's voltage, a divider.
  • Both cases together: Question 9 on this exam. \(R_2\) closes a loop with the source, so it is part of a divider (\(V_{R2} = 10\) V). \(R_3\) leads to the open terminal A and drops nothing, so \(V_{AB} = V_{R2}\).
  • Several branches: reduce series and parallel parts (or use KVL/nodal analysis). Remember that a resistor leading to an open terminal still carries no current, so it drops nothing.
  • Asked for the whole Thévenin equivalent: \(V_{TH}\) is the open-circuit voltage you just found. For \(R_{TH}\), replace the source with a short and combine the resistors as seen from A–B. Here \(R_{TH} = 10 + 10 + 20 = 40\ \Omega\).
