Look at how the three branches connect. Every branch is a source in series with a resistor, and all three join the same two nodes (the top rail and the bottom rail). Which technique gives the voltage between those two nodes in one formula?

In Millman’s formula each \(V_k\) carries a sign: + if its + terminal faces the top rail, − if it faces the bottom rail. Check the sign beside each battery and its symbol (long plate = +) before you add anything up.

Once you have \(V_{ab}\), each resistor sits between node a and the top of its own battery. Its voltage is the difference of those two node voltages, and its current is that voltage over its resistance. Current flows from the higher-voltage end to the lower-voltage end, so compare \(V_{ab}\) with each battery voltage before you draw an arrow.

  1. The circuit has three branches, and each branch is a voltage source in series with a resistor. All three branches connect between the same two nodes: the top rail (call it a) and the bottom rail (b). This is exactly the “Millman circuit”, and the question says to use Millman’s theorem.

    Millman’s theorem gives one number: \(V_{ab}\), the voltage of the top rail relative to the bottom rail. The question asks for the voltage across and current through each resistor, so there is a second stage: use \(V_{ab}\) to find each branch’s resistor voltage, then Ohm’s law for its current.

  2. Millman’s formula needs three conditions, and all three hold here:

    • every branch is a voltage source with a resistor in series (no branch is a bare source);
    • all branches are connected between the same two nodes, a and b;
    • nothing else is connected between a and b (no load), so the formula gives the actual rail voltage.

    Once \(V_{ab}\) is known, every node voltage in the circuit is known. Take b as the 0 V reference. The top of each battery is at \(V_k\) (set by the battery), and node a is at \(V_{ab}\). Each resistor is connected between those two known voltages, so its voltage and current follow directly.

    Millman’s formula is single-node KCL in disguise: the branch currents into node a must add to zero, because a is not connected to anything else. That gives the check at the end.

  3. Sign of each source in the formula. \(V_k\) counts as positive if its + terminal faces node a, negative if its + terminal faces node b.

    • \(V_1\): “+” printed at its top, long plate on top → + toward a → enters as \(+4\ \text{V}\).
    • \(V_2\): “+” printed at its top, long plate on top → + toward a → enters as \(+10\ \text{V}\).
    • \(V_3\): long plate on top; the faint sign at its top is read as “+” → + toward a → enters as \(+6\ \text{V}\). (This reading is likely but not certain; see the source note. The reversed case is worked in the last step.)

    Voltages. All voltages are measured from node b (0 V). \(V_{ab} = v_a - v_b\). The top of battery \(k\) is at \(v_k = V_k\): +4 V, +10 V and +6 V.

    Currents. In each resistor the current flows from its higher-voltage end to its lower-voltage end. Below, “up” means from the battery toward node a, and “down” means from node a toward the battery. The question asks for voltage and current values plus a separate arrow, so the values are given as magnitudes and the direction is given by the arrow.

  4. Millman’s theorem:

    \[ V_{ab} = \frac{\dfrac{V_1}{R_1} + \dfrac{V_2}{R_2} + \dfrac{V_3}{R_3}}{\dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3}} \]
    \(V_{ab}\)
    voltage of node a relative to node b, V
    \(V_k\)
    signed source voltage of branch \(k\) (+ if its + faces a), V
    \(R_k\)
    series resistance of branch \(k\), Ω
    \(V_k/R_k\)
    source-transformed current of branch \(k\), A; their sum is the Norton current \(I_N\)
    \(1/R_k\)
    conductance of branch \(k\), S (siemens, 1/Ω); \(1/\sum(1/R_k)\) is the equivalent resistance \(R_N\)

    Resistor voltage and current (branch \(k\), battery top at \(v_k\)):

    \[ V_{Rk} = \lvert v_k - V_{ab} \rvert, \qquad I_{Rk} = \frac{V_{Rk}}{R_k} \]

    If \(v_k > V_{ab}\), the current flows up through \(R_k\) into node a. If \(v_k < V_{ab}\), it flows down. If \(v_k = V_{ab}\), no current flows.

    KCL at node a: the currents flowing up into a must equal the currents flowing down out of a.

  5. Each branch \(V_k\) in series with \(R_k\) is equivalent to a current source \(V_k/R_k\) in parallel with \(R_k\). All three sources have + on top, so all three arrows point up toward a.

Approach for a similar problem.

  1. Check the shape: every branch a source (or nothing) in series with a resistor, all between the same two nodes. If a branch connects to a third node, Millman does not apply directly; use nodal analysis or reduce the circuit first.
  2. Sign every source: + if its + terminal faces the node you call a, − if reversed, 0 for a resistor-only branch (its \(1/R_k\) still goes in the denominator).
  3. Compute \(V_{ab} = \sum (V_k/R_k) / \sum (1/R_k)\).
  4. For each resistor, use KVL around its branch: \(V_{Rk} = \lvert V_k - V_{ab}\rvert\), with \(V_k\) signed as in step 2 (0 for a resistor-only branch), and \(I_{Rk} = V_{Rk}/R_k\). If \(V_k > V_{ab}\), the branch current flows toward node a; if \(V_k < V_{ab}\), it flows away from node a; if \(V_k = V_{ab}\), the branch carries no current and gets no arrow. Inside the resistor the arrow points from its higher-voltage end to its lower one.
  5. Check KCL at node a: the currents in must equal the currents out.

If the arrangement changes: a battery drawn below its resistor or above it changes neither the resistor voltage nor the branch current, because both come from KVL around the whole branch (step 4). The order only changes where the resistor’s + end physically sits: with the battery above the resistor, the resistor’s other end is node b (0 V), not node a. With a load \(R_L\) across a–b, treat it as one more branch with \(V = 0\), or use the equivalent \(V_{ab}\) in series with \(R_N = 1/\sum(1/R_k)\). With all resistors equal, \(V_{ab}\) is the plain average of the signed source voltages.
