  2. Before (\(t < 0\), switch at B): the common terminal of S1 connects to contact B, which is wired straight to the bottom wire. \(R_1\) and \(L_1\) form a closed loop with no source, and the battery is disconnected. The question tells you the inductor current is 0 A.

    The inductor's current cannot jump, so at \(t = 0^+\) it is still 0 A. The current then rises.

  3. In a series RL loop the current follows the universal time-constant curve. The chart lists its values at whole time constants: 63.2 % at 1τ, 86.5 % at 2τ, 95 % at 3τ, and so on. You can read the chart directly only when \(t\) is exactly 1τ, 2τ, 3τ…

  4. Time constant of a series RL circuit:

    \[ \tau = \frac{L}{R} \]

    \(\tau\) in seconds (s), \(L\) in henries (H), \(R\) in ohms (Ω).

    Final (maximum) current: once the current stops changing, the inductor acts like a wire, so only \(R\) limits it: \(I_{max} = V_1/R\), in amperes.

    Current build-up (starts at 0, rises toward \(I_{max}\)):

    \[ i(t) = \frac{V_1}{R}\left(1 - \mathrm{e}^{-t/\tau}\right) \]

    Voltages (Ohm's law for the resistor, KVL for the inductor):

    \[ V_R(t) = i\,R = V_1\left(1 - \mathrm{e}^{-t/\tau}\right), \qquad V_L(t) = V_1 - V_R = V_1\,\mathrm{e}^{-t/\tau} \]

    Here \(t\) is the time since the switch moved to A, in seconds, and \(\mathrm{e} \approx 2.71828\).

Approach for a similar problem.

  1. Draw the circuit for each switch position. Find the initial current (here 0 A; an inductor's current cannot jump) and the final current \(I_{max} = V/R\) for the new position.
  2. Find \(\tau = L/R\), where \(R\) is the resistance in the loop the inductor is in after the switch moves.
  3. Convert every asked time to \(t/\tau\). If it is a whole number, the chart value is exact; otherwise use the equations.
  4. Build-up (current rising from 0, like here): \(V_R = V(1 - \mathrm{e}^{-t/\tau})\), \(V_L = V\mathrm{e}^{-t/\tau}\).
  5. Decay (switch moved from A to B after the current had built up): the source is gone. \(i = I_0\,\mathrm{e}^{-t/\tau}\), \(V_R = I_0 R\,\mathrm{e}^{-t/\tau}\), and \(V_L\) has the same size as \(V_R\) but opposite polarity, because the inductor is now the source in the loop.
  6. Different numbers: a larger L or smaller R makes τ longer and everything slower. If the decay loop has a different resistance than the build-up loop, it has its own τ.
  7. Check: \(V_R + V_L = V\) during build-up, and \(V_R = -V_L\) during decay.
