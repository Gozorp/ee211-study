Overview

This lecture covers Millman's theorem: a shortcut for finding the voltage across a set of parallel branches, where each branch is a voltage source in series with a resistor. The instructor first states the formula. He then derives it with tools the class already knows: a source transformation of every branch, a Norton equivalent (short-circuit current and resistance with the sources disabled), and a final source transformation back to a Thévenin-style source. A long Q&A covers why the resistance part is "one over a sum of inverses", when that resistance matters (only when a load draws current), and why the fraction is not simplified further. The lecture ends with a practical use, the binary-weighted resistor digital-to-analog converter (DAC).

Learning objectives

After this lesson you should be able to…

  • Recognise a "Millman circuit": several branches, each a voltage source in series with a resistor, all connected in parallel between two nodes.
  • Write Millman's formula from memory and compute the output voltage for any number of branches.
  • Derive the formula step by step: source transformation → short-circuit (Norton) current by KCL → Norton resistance with sources disabled → transform back.
  • Explain why the shorted terminals carry zero current through every branch resistor, and why \(I_N = \sum V_k/R_k\).
  • Disable sources correctly: voltage sources → short circuit, current sources → open circuit.
  • Find the equivalent series resistance \(R_N = 1/\sum(1/R_k)\) and say when it matters (when a load draws current).
  • Explain how a binary-weighted resistor DAC is a Millman circuit, and read a 4-bit DAC table (step size 0.3125 V for 5 V and 16 levels).

Prerequisites

Source transformation (st1)
A voltage source \(V\) in series with \(R\) is equivalent at its terminals to a current source \(I = V/R\) in parallel with the same \(R\), and back with \(V = IR\). The arrow points toward the + side.
Norton and Thévenin equivalents (tn1, tn2, tn3)
\(I_N\) is the current through a short placed across the two terminals. \(R_N = R_{TH}\) is the resistance seen between the terminals with all independent sources disabled. \(V_{TH} = I_N R_N\).
Kirchhoff's current law (KCL)
The currents entering a node add up to the currents leaving it. This is how the branch currents pile up along the top wire.
Resistors in parallel
\(R_{eq} = \dfrac{1}{1/R_1 + 1/R_2 + \cdots + 1/R_n}\). For exactly two resistors this equals \(\dfrac{R_1R_2}{R_1+R_2}\).
A short across a resistor
A wire in parallel with a resistor forces 0 V across it, so by Ohm's law no current flows through that resistor.

1. Millman's theorem: the circuit and the formula

Millman's theorem is "one of our network analysis techniques" . It answers one question: what is the voltage between the two rails when several branches, each a voltage source in series with a resistor, are all connected in parallel ? There can be any number of such branches.

The result, which "you could quite literally just remember" :

\[ V_{out} = \frac{\dfrac{V_1}{R_1} + \dfrac{V_2}{R_2} + \dfrac{V_3}{R_3} + \cdots + \dfrac{V_n}{R_n}}{\dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3} + \cdots + \dfrac{1}{R_n}} = \frac{\displaystyle\sum_{k=1}^{n} \frac{V_k}{R_k}}{\displaystyle\sum_{k=1}^{n} \frac{1}{R_k}} \]
\(V_{out}\)
voltage of the top rail relative to the bottom rail, V
\(V_k\)
source voltage in branch \(k\) (+ toward the top rail), V
\(R_k\)
series resistance in branch \(k\), Ω
\(n\)
number of parallel branches

How to remember it –: the numerator is each branch's voltage divided by its resistance, "however many we have, they all get added up". The denominator is one over each resistance, added up. "It does seem like it's a lengthy equation to remember, but it's really not that bad" . Use it whenever you have parallel branches of (voltage source + series resistor) and want the voltage across them.

The instructor calls this "an incredibly useful technique". He expects to use it in the 311 course in three, possibly four, situations . Rather than only memorise it, he derives it because the derivation "uses all the techniques we've kind of learned about thus far" .

2. Derivation plan: aim for a single source with a series resistor

Under the heading "Derivation…" and the question "How do we arrive at this?" , the instructor starts a new page. He redraws the network with \(V_1, R_1\), \(V_2, R_2\), …, \(V_n, R_n\) .

Whatever the network is, seen from its two terminals it must reduce to a voltage source in series with a resistance . "This looks very familiar": it is the form a Thévenin equivalent circuit gives . He labels the resistor \(R\) "\(R_{TH}\)" and the source \(V\) "\(V_{TH}\)" . The goal of the derivation is to find that \(V\) (Millman's voltage) and, along the way, that \(R\).

The route he takes (each step below) is: transform every branch → find the Norton equivalent (\(I_N\), \(R_N\)) → transform the Norton equivalent back into this Thévenin form.

3. Step 1 — Source-transform every branch

"The first thing we can go ahead and do … is to actually do a source transformation on each one of our voltages" . The page heading is "1) Source Transformation" . As learned last class (source transformation), a voltage source in series with a resistor becomes a current source in parallel with the same resistor. The current comes from Ohm's law :

\[ V_k \text{ in series with } R_k \;\Longrightarrow\; I_k = \frac{V_k}{R_k} \text{ in parallel with } R_k \]
\(I_k\)
current of the new source in branch \(k\), A (arrow up, toward the top rail, because each \(V_k\) has its + on top)
  • Branch 1: \(V_1/R_1\) in parallel with \(R_1\)
  • Branch 2: \(V_2/R_2\) in parallel with \(R_2\) — "again just source transformation"
  • …and so on to branch \(n\): \(V_n/R_n\) in parallel with \(R_n\)

"Now we've done our source transformation and we've turned our top circuit into this" . The next job is the Norton equivalent of this circuit. The heading is extended to "1) Source Transformation & find Norton Equivalent: \(R_N\) & \(I_N\)" .

4. Step 2 — Norton current: short the output terminals

To find a Norton equivalent we need \(I_N\) and \(R_N\) . The instructor writes them with a capital N, "so that we're not confusing it with the little \(R_n\)" of the last branch . He starts with the current .

Method: short the two terminals ("we're finding it from the perspective of these two terminals") and find the current through that short, drawn in red .

Derivation of \(I_N\)

1. Is the short in parallel with each resistor? The instructor asks the class this . Yes: every \(R_k\) connects the top rail to the bottom rail, and so does the short.

2. Current in each resistor (Ohm's law). The short forces 0 V across every \(R_k\), so \(i_{R_k} = 0/R_k = 0\). "I have zero current going through \(R_1\). This is why applying Norton equivalent circuit to this is so easy, because this short ends up canceling out all of our resistances" .

3. Where does the source current go? (KCL at the top of branch 1.) With 0 A going down through \(R_1\), all of \(V_1/R_1\) must flow along the top wire .

4. KCL at the top of branch 2. \(V_1/R_1\) arrives from the left and \(V_2/R_2\) arrives from branch 2 (again 0 A in \(R_2\)), so the wire to the right carries \(V_1/R_1 + V_2/R_2\) .

5. Continue to the last branch. Every branch adds its current. Everything ends up in the short:

\[ I_N = \frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots + \frac{V_n}{R_n} = \sum_{k=1}^{n}\frac{V_k}{R_k} \]
\(I_N\)
short-circuit (Norton) current, A

\(I_N = \sum V_k/R_k\) . This is already the numerator of Millman's formula. "We actually have the first piece of the puzzle" .

At the instructor summarises this as "the voltage divided by all the resistances summed up". The precise statement is: each voltage divided by its own resistance, then those quotients summed, as written on the page.

5. Step 3 — Norton resistance: disable the sources

For \(R_N\) we go back to the transformed circuit, with no short this time, and disable the sources . The page heading is "2) Now find \(R_N\) (Norton: Short Voltages / Open Currents)" .

\[ \text{Disable a voltage source} \to \text{short circuit}; \qquad \text{disable a current source} \to \text{open circuit} \]

The class already knew that a voltage source is disabled by shorting it . The new piece in this lecture is that a current source is disabled by opening it: "you just leave it open … you remove the current source, it's no longer a part of your circuit" –.

Why open? A disabled source must deliver zero of whatever it controls. A voltage source set to 0 V keeps 0 V across itself, which is a wire. A current source set to 0 A lets no current through, which is a break in the circuit.

Plucking out every current source leaves "a bunch of resistances in parallel with each other" :

"It's just a bunch of resistors in parallel, so we can apply our parallel equation" :

\[ R_N = \frac{1}{\dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots + \dfrac{1}{R_n}} = \frac{1}{\displaystyle\sum_{k=1}^{n}\frac{1}{R_k}} \]
\(R_N\)
Norton (= Thévenin) resistance seen at the terminals, Ω

This is the resistance in series with Millman's voltage source.

Same answer without step 1. Disabling the original voltage sources (shorting them) also leaves \(R_1, \ldots, R_n\) in parallel. Source transformation does not change the resistance seen from the terminals.

6. Step 4 — Norton equivalent, then transform back: Millman's formula

With \(I_N\) and \(R_N\) known, the whole network is a Norton equivalent circuit . The target was a Thévenin-form circuit, so "we can apply source transformation one more time" .

Putting it together

1. Resistance stays the same in a source transformation: the series resistor is \(R_N\) .

2. Ohm's law to go from the current source to the voltage source: \(V = I_N R_N\) .

3. Substitute the results of steps 2 and 3 :

\[ V = I_N \cdot R_N = \left(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots + \frac{V_n}{R_n}\right) \cdot \frac{1}{\dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots + \dfrac{1}{R_n}} \]

4. Write it as one fraction . Multiplying by \(R_N\) puts the sum of inverse resistances in the denominator:

\[ V = \frac{\dfrac{V_1}{R_1} + \dfrac{V_2}{R_2} + \cdots + \dfrac{V_n}{R_n}}{\dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots + \dfrac{1}{R_n}} \qquad\text{in series with}\qquad R_N = \frac{1}{\dfrac{1}{R_1} + \cdots + \dfrac{1}{R_n}} \]

"Exactly what we had in the first place" : the same formula you would find for Millman's theorem in a book . Both results are boxed in red on the page .

Recap of the method: source transformation → Norton equivalent (find \(I_N\) and \(R_N\)) → put it back together . He calls it "the most convenient and easiest process to arrive at this equation". Other techniques would probably reach the same equation, but this route is "the simplest and most straightforward" .

Q: "Why is the numerator 1?"

This question is about the \(R_N\) expression. It is the general formula for resistors in parallel. For two resistors the class had also used \(R_1R_2/(R_1+R_2)\), but with many resistors in parallel, "one over the summation of the inverse of all of our resistances" is the more useful form –.

Cross-check with nodal analysis. Call the top-rail voltage \(v\) (bottom rail = 0 V). KCL at the top node, with branch \(k\) carrying \((v - V_k)/R_k\) downward and nothing connected to the terminals: \(\sum_k \dfrac{v - V_k}{R_k} = 0 \;\Rightarrow\; v\sum_k \dfrac{1}{R_k} = \sum_k \dfrac{V_k}{R_k} \;\Rightarrow\; v = \dfrac{\sum V_k/R_k}{\sum 1/R_k}\). So Millman's theorem is single-node KCL in disguise. (Checked symbolically in Python for \(n = 3\).)

7. Questions from class: \(R_N\), the load, and simplifying the formula

Is \(R_N\) just the sum of all the resistances?

No. A student asked whether "one over the inverse" simply equals the sum of the resistances . You add the inverses and then invert the total. "If you were to just sum up all your resistances, that would be them in series" .

Example: 200 Ω and 200 Ω in parallel: \(1/(1/200 + 1/200) = 100\ \Omega\), not 400 Ω. The parallel result is always smaller than the smallest branch resistance.

Voltage vs. resistance: when does \(R_N\) matter?

A student was confused about finding "\(V_{TH}\)" instead of "the voltage between the terminals". They are the same thing: \(V_{TH}\) is the Millman voltage between the two terminals . The original statement of Millman's theorem only mentioned that voltage, not the resistance .

  • If all you want is the voltage between the two points, with nothing connected, the voltage formula is "the only equation we need" .
  • "Once you attach something over here and you start having current flow through it", then \(R_N\) "comes into play" , because the load current makes a voltage drop across \(R_N\).
  • In practical Millman circuits the current drawn is usually tiny (microamps, "negligible to zero"). Zero current means zero drop across \(R_N\), so you generally only care about the voltage –.
  • If you connect a resistor that draws "a large amount of current" (milliamps, half an amp, an amp), then the \(R_N\) equation applies .

Load current formula. With a load \(R_L\) across the terminals, the Thévenin form gives \(I_L = \dfrac{V_{out}}{R_N + R_L}\) and \(V_L = V_{out}\dfrac{R_L}{R_N + R_L}\). If \(R_L \gg R_N\), then \(V_L \approx V_{out}\). That is the "negligible current" case the instructor describes. A numeric example is in section 9.

Can the formula be simplified ("flip and multiply")?

Another student asked why the formula is kept as a fraction of sums, instead of flipping the denominator and multiplying it out –. The instructor has "always seen and used it in this format". He thinks rewriting it just gets "overly complicated with no benefit" . The student concluded the same: with, say, 10 terms you would have to put everything over a lowest common denominator and distribute it across all of them, "a horrible equation" –.

Equal resistors (student's observation) : if all resistances are equal, the parallel resistance is the resistance divided by the number of resistors. Example: two 200 Ω resistors, \(1/200 + 1/200 = 2/200\), so 100 Ω . The instructor agrees, but says this only works when the resistances are the same. In practical circuits the branch resistances are almost always different, so use the general formula –.

With \(n\) equal resistors \(R\), Millman's formula becomes \(V_{out} = \dfrac{\sum V_k/R}{n/R} = \dfrac{V_1 + V_2 + \cdots + V_n}{n}\), the plain average of the source voltages, and \(R_N = R/n\).

8. Application: the binary-weighted resistor DAC

"It's always hard to justify … why am I doing this without seeing where it could be applicable" . So the instructor shows a circuit from his notes, titled "Binary Weighted Resistor DAC". It is drawn "in a different form than you're probably used to seeing": the ends of all the resistors are tied together at \(V_{out}\) .

  • Each input "can either be five volts or zero volts": a digital logic level, high or low, true or false .
  • The resistors are R, 2R, 4R, 8R, "powers of two". Each one is "weighted according to the binary bit position" –.
  • Look at just two of the inputs: each is "a voltage in series with a resistor", and they are all joined at one node. "This is Millman's", so you can use Millman's theorem to find \(V_{out}\) –.
  • Purpose: turn a binary value into an analog value (1 V, 1.2 V, 2 V, 2.3 V …). Digital logic (as in the 201 course) only has 0 and 1, i.e. 0 V and 5 V –. There are several DACs "inside of your PC as we speak" .

Which bit is the MSB? The notes put \(V_{B0}\) on the smallest resistor R, and the instructor says "bit position zero gets R" . The smallest resistor gets the largest weight (it has the largest \(1/R_k\)). So for a correct binary DAC, the input on R must be the most significant bit. On the 4-bit table page shown later, \(D_0\) is labelled the LSB. If \(B_0\) also meant the LSB here, the weights would be reversed. The video does not settle this. Treat "R ↔ MSB, 8R ↔ LSB" as the rule.

Possible note error. In the 3-bit pencil sketch at , the third resistor reads 3R. For binary weighting (R, 2R, 4R) it should be 4R, as on the 4-bit page above it. The instructor does not comment on the value.

He then shows two pages of block-diagram notes :

  • "DAC – Digital to Analog Converter": an 8-bit DAC with inputs \(D_0 \ldots D_7\) and one output \(V_{out}\). "In general" it takes a digital value (e.g. 10101010) and turns it into an analog value, usually a voltage .
  • 4-bit DAC : \(D_{in} = D_3D_2D_1D_0\) (\(D_3\) = MSB, \(D_0\) = LSB), \(V_{ref} = 5\ \text{V}\), \(V_{out}\) = 0 to 5 V. "With 4 bits we can only represent voltages on the range 0 to 5 V with \(2^4 = 16\) discrete values." The inputs run over the codes 0000 to 1111 (0 to F) .

The 4-bit DAC table from the notes

Given (on the page): \(V_{ref} = 5\ \text{V}\), 4 bits, step size 0.3125 V. Each code "gets converted to \(V_{out}\)" as code × step size.

1. Number of levels: \(2^4 = 16\).

2. Step size (the change produced by one LSB): \(5\ \text{V}/16 = 0.3125\ \text{V}\).

3. Output = decimal value of the code × 0.3125 V:

\(D_3D_2D_1D_0\)decimal\(V_{out}\)
000000(0.3125 V) = 0 V
000111(0.3125 V) = 0.3125 V
001022(0.3125 V) = 0.625 V
100088(0.3125 V) = 2.5 V
11101414(0.3125 V) = 4.375 V
11111515(0.3125 V) = 4.6875 V, written as "5 V or 4.6875" with the note "Different DAC designs"

The outputs step through 16 evenly spaced voltages between 0 and about 5 V. "Step size: the smallest change that can be produced. In other words, the LSB produces a voltage change equal to the step size." (all values checked in Python)

The step-size formula at the bottom of this page ("Stepsize = \(V_{ref}\)/…") is cut off at the frame edge, and the instructor only skims the page (–). The table values are consistent with \(V_{ref}/2^4 = 0.3125\ \text{V}\).

Millman applied to the R–2R–4R–8R network (not done in the video). Put the MSB on R and the LSB on 8R, each input 0 V or 5 V, and nothing connected to the output. Then

\[ V_{out} = \frac{\dfrac{5b_3}{R} + \dfrac{5b_2}{2R} + \dfrac{5b_1}{4R} + \dfrac{5b_0}{8R}}{\dfrac{1}{R} + \dfrac{1}{2R} + \dfrac{1}{4R} + \dfrac{1}{8R}} = \frac{5\,(8b_3 + 4b_2 + 2b_1 + b_0)/8R}{15/8R} = \frac{5\ \text{V}}{15}\times(\text{code}) \]

So this passive network has a step of \(5/15 = 0.333\ \text{V}\): 0001 → 0.333 V, 1000 → 2.667 V, 1010 → 3.333 V, and 1111 → exactly 5 V. That matches the "5 V" option in the table. Designs with step \(V_{ref}/16\) reach only \(15/16 \times 5 = 4.6875\ \text{V}\), the other option. The \(R_N\) of this network is \(1/(15/8R) = 8R/15\). A load on \(V_{out}\) would pull the voltages down, which is why real DACs buffer the output.

Two-input example in the pencil notes (not discussed aloud)

Lower on the same notes page is a two-input version: \(V_{B0} = 3\ \text{V}\) through R and \(V_{B1} = 1\ \text{V}\) through 2R, joined at \(V_{out}\). Next to it is the partly hidden expression \(\dfrac{(V_{B0} - V_{B1})\,2R}{3R}\) .

1. Millman: \(V_{out} = \dfrac{3/R + 1/(2R)}{1/R + 1/(2R)} = \dfrac{3.5/R}{1.5/R} = \dfrac{7}{3}\ \text{V} \approx 2.33\ \text{V}\). (The value of R cancels.)

2. Same thing, done the way the notes' expression suggests. The loop current is \((3-1)/(R+2R) = 2/(3R)\). The drop across 2R is \((V_{B0}-V_{B1})\cdot 2R/3R = 4/3\ \text{V}\). So \(V_{out} = 1 + 4/3 = 7/3\ \text{V}\).

\(V_{out} = 7/3\ \text{V} \approx 2.33\ \text{V}\) (Python-checked).

Under "\(V_{out}\)" the notes appear to read "2 V" . The pencil is faint and partly covered by the instructor's hand, and he never talks about this example. The exact Millman result is 2.33 V. If the note really says 2 V, it is rounded or a slip.

Why learn any of this? "Because it makes us better engineers" –. Millman's theorem lets you analyse circuits like the DAC, which take digital 0/5 V values and produce a continuous range of 0 to 5 V.

9. Using the formula in practice: polarity, source-free branches, load current (additional)

This whole section is additional teaching. The video draws every source with + facing the output rail, gives no numeric example, and does not discuss reversed sources or branches without a source.

Sign convention. \(V_{out}\) is the voltage of the top (output) rail relative to the bottom (reference) rail. In each branch, take \(V_k\) as positive if its + terminal faces the output rail (as in all the instructor's drawings), and negative if it is reversed (+ toward the reference rail). This follows from the source transformation: a reversed source becomes a current source whose arrow points down, so it subtracts from \(I_N\).

Branch with no source. A branch that is just a resistor \(R_k\) has \(V_k = 0\). It adds nothing to the numerator, but its \(1/R_k\) still goes in the denominator. It pulls \(V_{out}\) toward 0 V and lowers \(R_N\).

Load. A load resistor across the terminals can be treated as one more source-free branch. Or use the Thévenin form: \(I_L = V_{out}/(R_N + R_L)\).

Example — three branches with one reversed source, one source-free branch, and a load (added for practice)

Given: branch 1: \(V_1 = 12\ \text{V}\) (+ up) in series with 2 kΩ. Branch 2: a 6 V source reversed (+ down) in series with 3 kΩ. Branch 3: 6 kΩ with no source. Load \(R_L = 3\ \text{k}\Omega\). Goal: \(V_{out}\) without the load, \(R_N\), and the load current and voltage.

1. Signs: \(V_1 = +12\ \text{V}\), \(V_2 = -6\ \text{V}\) (reversed), \(V_3 = 0\) (no source).

2. Numerator (this is \(I_N\)): \(\dfrac{12}{2\,\text{k}} + \dfrac{-6}{3\,\text{k}} + \dfrac{0}{6\,\text{k}} = 6\ \text{mA} - 2\ \text{mA} + 0 = 4\ \text{mA}\).

3. Denominator: \(\dfrac{1}{2\,\text{k}} + \dfrac{1}{3\,\text{k}} + \dfrac{1}{6\,\text{k}} = \dfrac{3 + 2 + 1}{6\,\text{k}\Omega} = \dfrac{1}{1\,\text{k}\Omega}\), so \(R_N = 1\ \text{k}\Omega\).

4. Open-circuit (Millman) voltage: \(V_{out} = 4\ \text{mA} \times 1\ \text{k}\Omega = 4\ \text{V}\).

5. With the load: \(I_L = \dfrac{4\ \text{V}}{1\,\text{k}\Omega + 3\,\text{k}\Omega} = 1\ \text{mA}\), \(V_L = 1\ \text{mA} \times 3\ \text{k}\Omega = 3\ \text{V}\).

6. Check by KCL at node \(v = 3\ \text{V}\): branch currents downward are \((3-12)/2\text{k} = -4.5\ \text{mA}\), \((3-(-6))/3\text{k} = +3\ \text{mA}\), \(3/6\text{k} = +0.5\ \text{mA}\), \(3/3\text{k} = +1\ \text{mA}\). Sum \(= 0\) ✔. Alternatively, include \(R_L\) as a fourth source-free branch: \(\dfrac{4\ \text{mA}}{1/1\text{k} + 1/3\text{k}} = 3\ \text{V}\) ✔.

\(V_{out} = 4\ \text{V}\) open-circuit, \(R_N = 1\ \text{k}\Omega\). With the 3 kΩ load: \(I_L = 1\ \text{mA}\) and \(V_L = 3\ \text{V}\) (all verified in Python).

Assumptions & limitations

  • Circuit shape as taught: parallel branches, each a voltage source in series with a resistor, between the same two terminals .
  • Open-circuit voltage. \(V_{out}\) from the formula is the voltage with no load current . With a load, use the Thévenin form \(V_{out}\) in series with \(R_N\) . When the load current is microamps, the difference is negligible .
  • Polarity. As drawn in the video, every source has + toward the output rail.
  • Linear resistive DC circuits (the derivation uses only source transformation, KCL and Ohm's law).
  • Equal-resistor shortcut (\(R_N = R/n\)) works only if all branch resistances are equal .

Circuit shape. The formula applies to branches that are each a voltage source in series with a resistor (or a resistor alone), all connected between the same two nodes. If branches connect to other nodes in between, reduce the circuit first or use nodal analysis.

Every source needs a series resistance. An ideal voltage source with \(R_k = 0\) would make \(V_k/R_k\) and \(1/R_k\) infinite. That node voltage is then simply forced to \(V_k\) (two such sources with different values would be a contradiction).

Reversed sources enter with a minus sign, and source-free branches with \(V_k = 0\) (see section 9).

Common mistakes

Adding resistances instead of inverses. \(R_N \ne R_1 + R_2 + \cdots\). That would be series . Check: \(R_N\) must be smaller than the smallest \(R_k\).

Dropping \(1/R_k\) for a branch without a source. It contributes 0 to the numerator but must stay in the denominator.

Ignoring polarity. A source whose + faces the reference rail enters as \(-V_k\).

Confusing \(R_N\) (Norton) with \(R_n\) (the last branch). The instructor uses a capital N for this reason .

Wrong way to disable a current source. Current sources are opened (removed), voltage sources are shorted . Shorting a current source would short out its parallel resistor and give \(R_N = 0\).

Thinking current flows through \(R_k\) when finding \(I_N\). With the terminals shorted, every \(R_k\) has 0 V across it and carries 0 A .

Using \(V_{out}\) as the load voltage when the load draws real current. Use \(V_L = V_{out}\,R_L/(R_N + R_L)\).

"Simplifying" the formula wrongly. \(\dfrac{\sum V_k/R_k}{\sum 1/R_k} \ne \sum V_k\). You cannot cancel \(R_k\) term by term. Keep it as a fraction of two sums .

DAC resistor order. The smallest resistor (R) must go with the most significant bit. Reversing them reverses the bit weights.

Recap & formula sheet

  • Millman circuit: \(n\) parallel branches, each \(V_k\) in series with \(R_k\), between two rails.
  • Derivation: transform every branch to \(V_k/R_k \parallel R_k\) → short the terminals: no current in any \(R_k\), so \(I_N = \sum V_k/R_k\) (KCL) → open the current sources: \(R_N = 1/\sum(1/R_k)\) → transform back: \(V = I_N R_N\).
  • Only the voltage formula is needed when (almost) no current is drawn. \(R_N\) matters with a real load.
  • Application: binary-weighted resistor DAC (R, 2R, 4R, 8R with 0/5 V inputs). A 4-bit, 5 V DAC has 16 levels, step 0.3125 V in the notes' table.

Millman voltage: \(V_{out} = \dfrac{\sum_{k=1}^{n} V_k/R_k}{\sum_{k=1}^{n} 1/R_k}\) (V). \(V_k\) is + if its + terminal faces the output rail, 0 for a branch with no source.

Equivalent (Norton = Thévenin) resistance: \(R_N = \dfrac{1}{\sum_{k=1}^{n} 1/R_k}\) (Ω)

Norton current: \(I_N = \sum_{k=1}^{n} V_k/R_k\) (A), and \(V_{out} = I_N R_N\)

Source transformation: \(I = V/R\) and \(V = IR\), same \(R\)

Disable sources: voltage source → short; current source → open

With a load \(R_L\) (additional): \(I_L = \dfrac{V_{out}}{R_N + R_L}\), \(V_L = V_{out}\dfrac{R_L}{R_N + R_L}\)

Equal resistors (additional): \(R_N = R/n\), \(V_{out} = (V_1 + \cdots + V_n)/n\)

DAC (notes): levels \(= 2^{\text{bits}}\); step \(= V_{ref}/2^{\text{bits}} = 5/16 = 0.3125\ \text{V}\); \(V_{out} = \text{code} \times \text{step}\)
